# 🚀 HireFlow AI

### AI-Powered Recruitment & Job Management Platform

HireFlow AI is a full-stack recruitment platform that connects candidates and employers through a modern, AI-assisted hiring workflow.

Candidates can discover jobs, save opportunities, apply with resumes and cover letters, track application status, and receive personalized AI-based career assistance.

Employers can post and manage jobs, review applicants, analyze resumes using AI, generate interview questions, create AI-powered cover letters, and accept or reject applications with email notifications.
